Exact Alarm Architecture

When the minute isn’t accurate enough.

Standard clock apps round every trigger to :00. ExactTime schedules down to the exact second for market opens, transit departures, lab intervals, broadcasts, and timed focus blocks.

Four Precision Schedule Modes

ONE_TIME · WEEKLY · INTERVAL · MONTHLY

Fire once on an exact calendar date and second, repeat on custom weekday bitmasks, cycle on intervals down to every 10 seconds, or trigger on a fixed day each month.

Pre-Alarm Lead Warnings & Fade-In

T-5s · T-10s · T-30s

Receive a subtle pre-alarm heads-up before T-0 arrives, pair with gradual audio fade-in (10s or 30s), and skip or restore the next occurrence with one tap.

Tactile Cadence & Vibration Profiles

SHARP_PULSE · DOUBLE_TAP · CONTINUOUS

Choose crisp haptic and audio tick intervals (1s, 5s, 10s, 30s) on the live chronometer, and assign distinct vibration patterns across 7 alarm categories.

Boot-Resilient Exact Delivery

AlarmManager · BootReceiver

Backed by Room persistence, a foreground ringing service, full-screen lock-screen alerts, and automatic rescheduling after device reboots.

Open Source Android App

Clone, inspect, and build from source.

ExactTime is built with modern Kotlin and Jetpack Compose with zero third-party ad SDKs or cloud dependencies. Build a debug APK locally with Android Studio or Gradle in seconds.

Terminal · Build & Install 
# Clone the repository
git clone https://github.com/kielforeman-collab/exact-time.git
cd exact-time

# Build the debug APK
./gradlew assembleDebug

# Install directly to a connected Android device
./gradlew installDebug
